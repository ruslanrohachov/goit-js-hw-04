# goit-js-hw-04

Домашнє завдання №4 з JavaScript на роботу з об'єктами: підрахунок значень,
обчислення середнього і методи об'єкта.

## Завдання

### Задача 1. Пакування товарів

Функція обчислює загальну кількість товарів в об'єкті `products` і повертає
`true`, якщо вона менша або дорівнює `containerSize`, і `false` — якщо ні.

### Задача 2. Розрахунок калорій

Функція повертає середньодобове значення калорій за тиждень.

### Задача 3. Профіль гравця

Об’єкт `profile` описує профіль користувача на ігровій платформі. У його
властивостях зберігається ім’я профілю `username` та кількість активних годин
`playTime`, проведених у грі.

## Чого я навчився

### Задача 1

- Отримувати масив значень об'єкта `products` за допомогою `Object.values()`.
- Створювати змінну для загальної кількості товарів і задавати їй початкове
  значення `0`.
- Перебирати масив значень циклом і додавати кожне число до загальної кількості.
- Порівнювати суму з `containerSize` і повертати результат цього порівняння.

### Задача 2

- Перевіряти крайовий випадок: якщо `days` — порожній масив, одразу повертати
  `0`.
- Створювати змінну для загальної кількості калорій і задавати їй значення `0`.
- Перебирати об'єкти в `days` і додавати значення їхніх властивостей `calories`.
- Ділити загальну кількість калорій на довжину масиву та повертати результат.

### Задача 3

- Додавати метод `changeUsername(newName)`, який змінює `this.username` на
  `newName`.
- Додавати метод `updatePlayTime(hours)`, який збільшує `this.playTime` на
  `hours`.
- Додавати метод `getInfo()`, який повертає рядок із поточними значеннями
  `this.username` і `this.playTime`.
